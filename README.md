# AWS Static Website Hosting Using Amazon S3

# Project Overview

This is my first AWS Cloud project. I created and hosted a static website using Amazon S3 (Simple Storage Service).

The website is publicly accessible through the Amazon S3 Static Website Hosting endpoint.

# Technologies Used

- Amazon S3
- AWS Management Console
- HTML
- CSS

# Project Objectives

- Create an S3 bucket.
- Upload static website files.
- Configure static website hosting.
- Configure bucket permissions and bucket policy.
- Deploy and access the website using the S3 website endpoint.

# Project Implementation

1. Created an Amazon S3 bucket.
2. Uploaded website files (index.html, error.html and style.css).
3. Enabled Static Website Hosting.
4. Configured the bucket policy.
5. Tested the website using the S3 website endpoint.
